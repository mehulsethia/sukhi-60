## Selection summary

- **Selected architecture:** a single new Next.js 16 (App Router, Node runtime) app on Vercel, with Supabase for Postgres + RLS, Auth, private Storage, Cron/pg_net/Vault, and an outbox job queue. The leading hypothesis (OpenCare + Aiden + HabitTrove reuse) was **not** taken as a code merge. No reference component could run as-is on Vercel/Supabase. Two of the four are AGPL, and the most reusable "code" (OpenCare's occurrence SQL, Aiden's WhatsApp sender) either needed fundamental changes or embodied unsafe patterns.
- **Copied code:** none. All Sukhi code was written independently from the brief. Design ideas are credited in `LICENSE_NOTES.md`.
- **All three pillars are implemented without depending on the references:** the assistant (`src/server/agent.ts`), evaluation (`src/domain/evaluation.ts`, `src/server/ai-tasks.ts`, SQL `apply_evaluation_internal`), and encouragement (SQL `_award`, `src/domain/rewards.ts`, `src/components/Garden.tsx`).
